# 磁盘、设备与构建产物约束（<项目名>）

本工作区用于离线手游复活改造。以下规则优先级**高于**任何“保留历史大包 / 保留中间产物 / 方便回看对比”的习惯。

## 1. 受保护路径（严禁误删或复制原包）
- 原始包 `<orig.apk>` 全项目只保留 **1 份**，严格只读，禁止在 `work/`、`dist/`、`evidence/` 复制。
- 源码、补丁脚本、分析文档、测试夹具与 `交接/` 受保护；正式存档只读保护。

## 2. 签名后立刻删中间包 + 滚动裁剪
- 生成最终签名包后，**同一命令内立刻删除** `unsigned.apk`、`aligned.apk`、`*.idsig`。
- `dist/` 覆盖式输出；若按轮次建候选目录，旧目录仅保留文本/JSON 审计，整个构建区最多留最新 **2 轮 `.apk`**。
- 每次 `adb push` 到设备端 `/data/local/tmp/` 完成安装或存档验证后，**当轮立刻删除设备端大文件**。

## 3. evidence 与可再生缓存
- `evidence/` 下单个超过 **20 MB** 的二进制（`.apk` / `.tar` / `.unity3d` / `.bin` / `.dll`），验收结论落盘后**当轮即删**。
- `evidence/` 截图 `.png` 与日志 `.log` 总量上限 **1 GB**，超出按修改时间从旧到新滚动清理。
- 每批结束清理 `tmp/`、`**/bin`、`**/obj`、`**/__pycache__`；删前必查 Windows junction/符号链接。

## 4. 磁盘预算与熔断（硬性）
- 本工作区总体积上限为 **`<15 或 20>` GB**；构建前必须运行 `disk_budget.py` 检查：所在盘剩余 **≥ 30 GB** 且工作区未超限，否则先清理达标再构建。

## 5. 唯一设备锁与安全边界
- 全项目任何时候只使用 `交接/设备锁.json` 登记的唯一设备，所有 `adb` 必须显式带 `-s <serial>`。
- 严禁 `adb shell svc wifi disable`、`adb kill-server`、`ldconsole quitall`、强杀 `Ld9BoxSVC` 或触碰其他模拟器实例。
- 恢复应用私有存档后必须 `chown <app_uid>:<app_uid>` + `chmod 0600`。

## 6. 唯一交接入口
- 接手前先读 `交接/HANDOFF.md`（覆盖式维护，≤ 120 行）、`交接/KICKOFF-AUTH.md` 与 `交接/PROGRESS-MATRIX.csv`。
