# 批次推进（开工之后的无人值班阶段）

这一页是长时间无人值守时的推进规矩，专治长时间无人值守中的**空转凑轮数、盲打诊断包、卡死单点不换项、文档膨胀烧光上下文、热推静默失效**五大顽疾。和 `skills/night-shift` 一起用：night-shift 管一晚上怎么值班，这页管每一批怎么挑、怎么止损。

---

## 每次开工 / 醒来的固定检查顺序（不跳过）

1. **读精简入口**：只读 `交接/HANDOFF.md`（≤ 120 行 / ≤ 5 KB 快照）、`交接/KICKOFF-AUTH.md`（预授权边界）与 `交接/BUG-LIST.md` 中最高优先级未修项；**绝不通读历史长日志或旧归档**。
2. **核设备、并发与热推身份**：用 `device_guard.py --check` 验证 `交接/设备锁.json` 中唯一设备在线且前台未被占用；装包/热推后核对日志中的 **Build ID / 热更文件哈希**，排除热更目录残留或 `GlobalVersion` 清目录导致的“改了代码没生效”。
3. **核基线绿灯**：先跑快集宿主回归（目标 ≤ 30 秒），不绿先修，不带半成品继续堆代码。
4. **选唯一批次目标**：取清单中**最靠前且未阻塞**的一项，每次只推进一项。

---

## 推进优先级（按玩家真实游玩路径）

1. **先修 P0/P1（崩溃 / 卡死 / 数据错 / 坏档）**；
2. **先清“已写代码但未真机实测”的欠账**（不堆一堆只有 Host 绿灯的模块）；
3. **按玩家顺序扩系统**：主线前段解锁 → 召唤/核心养成 → 背包/商店/代金券闭环 → 日常/签到/任务/福利 → PVE 副本/爬塔 → 竞技/公会/本地 AI 曲线对手 → 运营/节日活动（按“入口家族 × 模板”批量推进：每模板 1 个代表页做到 L3 + 同模板其余页 L1 + `verify_config` 全量配置对账）。

---

## 七条防空转规矩

1. **按“业务批次”推进，严禁凑“轮数”**
   - 只有让 `PROGRESS-MATRIX.csv` 至少一行状态跃迁、或关闭真实 BUG、或定位明确证据根因，才算一个有效批次；
   - **禁止将以下工作拆成独立批次**：错位威胁模型加固（单机防 `2**80` 余额）、对已过链路重复验证、纯改文档措辞、无后续实现的静态审计。
2. **硬时间盒与止损换项**
   - **回归问题优先二分与对照**（比上一个 Git commit、点其他按钮对照），**同一问题“加探针重打包”最多 2 轮**，严禁无日志盲打十几个包（遇到静默先强抛错验堆栈）；
   - **单一卡点连续 2 轮或 30–45 分钟无进展**：记录现象、已试方案、日志路径进 `阻塞清单` / `交接/求助.md`，**立刻换清单下一项**。
3. **开发期只热推，里程碑才打 APK**
   - 日常修复与扩协议走热推（0.3s–17s）+ 命令桥/UIProbe + 真实抓包请求 Host 回归；**绝不为单个小修复打几 GB 整包**；
   - 攒够一个系统大类（3–5 个模块或一批 BUG）且 Host 全绿后，先过 `disk_budget.py` 熔断再打一次配对包（Formal + GM），签后立刻删中间包并调 `device_guard.py --clean-tmp`。
4. **修一 BUG 必补一回归，写接口禁默认成功**
   - 每关闭一条真机 BUG 必须沉淀为 Host 契约或回放回归用例并入构建门禁；
   - 未实现写接口必须显式拒签并打日志，严禁靠“默认返回成功”掩盖丢道具/丢进度。
5. **未知原服规则按预授权 `D1` 走，不为此停工**
   - 按“原表直读 → 部分字段推导 → 参考同类系统”补齐，标 `[重建]` 记入 `交接/本地规则登记.md` 即继续；**坚持 1:1 原版 UI，未拍板绝不自绘壳**。
6. **多 Agent 并行边界（`staged/` + 冻源树）**
   - 最多并行 2–3 个子代理，按文件范围零冲突拆分（如：协议/无头单测线 vs 设备联调线）；
   - 并行改动先落 `staged/` 暂存，**编译与测试窗口内冻结源树**，避免边改边编造成漂移；构建主入口、补丁清单、存档 Schema、状态文件与设备验收只由主会话亲自收口。
7. **瘦身交接与 Git 纪律**
   - `交接/HANDOFF.md` 覆盖更新 **≤ 120 行（≤ 5 KB）**；`值班日志.md` 每批 ≤ 6 行；`PROGRESS-MATRIX.csv` 严分 `Host通过` / `仅入口通过` / `真机L3通过`；
   - 每批绿灯提交一次 Git commit（证据大文件不进 Git）；仅打包批次汇报磁盘统计。

---

## 停止条件（仅以下 4 种情况停下来找用户）

1. 即将触及 `AGENTS.md` 硬红线（如共享 `Ld9BoxSVC` 死锁需用户重启、原包/正式档异常、需人工介入真机）；
2. 磁盘熔断无法通过清理本工作区解决；
3. 计划批次全部完成（转入 `independent-qa.md` 终验）或全部进入阻塞清单；
4. 同一阻塞连续三次换项仍被同一外部环境根因挡住（或用户明确叫停）。

收尾输出**五段式短报告**：① 已验证（证据路径 + commit）② 已实现待设备验证 ③ 阻塞项与排查建议 ④ 待用户拍板（附当前保守默认值）⑤ 产物路径、磁盘健康与后台任务收尾状态。
