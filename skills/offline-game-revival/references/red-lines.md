# 全局硬红线（多项目、多模拟器并行时）

开工时把这页抄进项目的 `AGENTS.md`（模板见 `../templates/PROJECT-AGENTS.md`），优先级高于任何“保留历史大包 / 顺手操作其他模拟器 / 报喜不报忧”的习惯。其中几条命令级红线可以用 `../scripts/guard_hook.py` 在工具层拦住。

## 1. 工程结构、路径与真实性铁律

- **打包期改写，不以运行时注入作交付**：Frida / hook / 内存导出只作侦察手段；最终产物必须是“单装 APK（或离线包）、断网、不 root、不依赖电脑”的独立包。
- **1:1 原版 UI 优先**：未获用户明确拍板，严禁私自改写自绘壳或合成假界面，坚持用真协议复用原厂 UI 与 Handler。
- **单一主入口 + 锚点断言 + 扁平覆写**：补丁集中于可重放构建脚本并配显式断言；优先采用“只读原树 + `overrides/` + `offline/` 扁平覆写”替代长串易冲突补丁链，绝不手改反编译/解包产物。
- **零绝对路径硬编码**：所有脚本一律使用 `$PSScriptRoot` / `Path(__file__)` 相对推导工作区与 `tools/`，禁止写死盘符或目录绝对路径。
- **开工必建版本控制**：未建 Git 的项目第一步必须 `git init`（排除原包、大资源、构建产物与证据截图）；多 Agent 并行时统一用 `staged/` 暂存，**编测期间冻结源树**。
- **写接口严禁默认成功兜底**：未接协议仅允许只读查询安全兜底，**任何消耗/发奖/写档类协议未实现时必须显式拒签并打日志**，绝不静默返回“成功”掩盖数据丢失；缺失的原服算法/规则须显式标注 `[重建]` 并登记进 `交接/本地规则登记.md`。

## 2. 磁盘预算、打包与产物熔断（硬性）

- **原包唯一**：原始 APK / 基础资源快照全项目只读且只保留 **1 份**，严禁在 `work/`、`dist/`、`evidence/` 复制。
- **签后即删中间包 + 滚动裁剪**：生成最终签名包后，**同一命令内立刻删除** `unsigned.apk`、`aligned.apk`、`*.idsig`；`dist/` 覆盖输出，构建区最多保留最新 **2 轮 `.apk`**。
- **证据与设备端清理**：`evidence/` 禁存 > **20 MB** 二进制（结论落盘当轮即删），截图 `.png` 与日志 `.log` 总量上限 **1 GB**；每次 `adb push` 安装/验证或中转后**当轮删除设备端 `/data/local/tmp/*.apk`、`.tar`、`.bin`**，防 `.vmdk` 膨胀。
- **构建前熔断**：每次打包前必检所在盘剩余 **≥ 30 GB** 且工作区未超预算（默认 15–20 GB）；删任何目录前必查 Windows junction / 符号链接。
- **APK 封装红线**：保留原音频/视频 `ZIP_STORED` 压缩属性；超 ZIP32 上限（>65,535 条目或 >4 GB）改用外置 `Android/data/<pkg>/files/` 或单条 `ZIP_STORED` 首启自解压（验 `CanonicalPath`）；改 DEX 字节后必重算 SHA-1 与 Adler-32；`7za u` 必在 staging 根目录传相对路径。

## 3. 多项目并行、ADB 与模拟器防误伤红线

- **单项目单设备锁**：只认 `交接/设备锁.json` 登记的唯一序列号；所有 `adb` 必须显式带 `-s <serial>`，脚本硬编码拒接其他设备；装 32 位包前核 `ro.product.cpu.abilist`。
- **严禁全局杀伤命令**：绝对禁止 `adb kill-server`、`ldconsole quitall`、全局强杀 `adb` / `Ld9BoxSVC` / `dnplayer` / `MuMu` 或触碰无关实例。
- **每次点击先验前台**：执行 UI 点击前先核 `topResumedActivity` / `mCurrentFocus`；若前台为其他应用或被他任务占用，**立刻停手不抢、不杀进程**。
- **雷电模拟器断网陷阱**：**严禁 `adb shell svc wifi disable`**（会直接切断走 `wlan0` 的 ADB）。断网测试使用目标 UID `iptables`（测毕撤回）或带 `trap`/超时恢复的 guest 看门狗，并优先在正式包移除 `INTERNET` 权限。
- **Windows ADB 两坑**：① 涉及非 ASCII / 中文路径一律经 `/data/local/tmp/<guid>.bin` 中转；② PowerShell 5.1 调用 `adb` 须临时用 `Continue` 避免 stderr 被误判终止，**唯一以 `$LASTEXITCODE` 判错**。

## 4. 存档安全、原子落盘与隔离铁律

- **正式档绝对保护**：正式包与测试隔离包（独立包名/UID）物理分离；严禁修改、强停或自动覆盖用户正式档，操作前后以 SHA-256 校验保护；GM 档与虚拟时钟测试档永不转正式档，永不改系统时钟。
- **原子写档 + 幂等防重**：写档禁止“先 `remove` 再 `rename`”；使用带线程/进程后缀的 `.tmp` + `flush` + 备 `.bak` + POSIX `rename` / `File.Replace` 原子覆盖，读档支持 `主 → .bak → .tmp` 自愈；发奖/扣费须用 `tx_key` 幂等防双入账；JSON 序列化大数超 `int.MaxValue` 存字符串防溢出。
- **属主还原**：向 `/data/user/0/<pkg>/` 推回文件后，必须同步 `chown <app_uid>:<app_uid>` + `chmod 0600`。

## 5. 严口径验收与瘦身交接

- **三层证据分离**：`Host 通过` ≠ `真机通过` ≠ `视觉通过`；“能打开界面” ≠ “功能完成”。功能通过须满足：真实操作/原引擎真打胜负 → 账本对账 → 冷启一致 → 负例拒签。
- **封版冷启验收门槛**：正式包验收必须通过**彻底清数据重装 + 空热更目录 + 真断网双冷启（核换新 PID）+ 事务中途强杀验档 + 0 异常 + `aapt` 权限校验**；正式包物理关闭 `debuggable`/热载/全量日志/GM 后门。
- **唯一瘦身交接四件套**：`交接/HANDOFF.md` 覆盖维护 **≤ 120 行**（每批快照 ≤ 5 KB），配 `PROGRESS-MATRIX.csv`、`BUG-LIST.md`（修一 BUG 必补一回归）、`值班日志.md`（每批 ≤ 6 行），严禁每轮新建零散报告。
