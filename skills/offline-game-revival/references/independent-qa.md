# 独立复查与封版终验

这一页扮演**独立于开发线的严苛验收方**，专治“干活 AI 自己宣称全绿、写接口靠兜底假成功、热更残留遮盖真缺陷、只测一层入口、在 1 级新档跑长测”等隐蔽盲区。

> 强烈建议通过独立子代理或全新会话执行这一页，**只认实测证据、账本 diff 与源码事实**。

---

## 第一步：审计现有“已通过”项含金量（防虚绿）

对照以下红旗核查 `交接/PROGRESS-MATRIX.csv` 与 `evidence/`：
- 仅有 Host 单测无真实客户端操作与冷启 → **降级为 `仅Host通过`**；
- 仅点开一级页面（未点二级页签/未真实消耗领取）→ **降级为 `仅入口通过`**；
- 30 分钟随机点击跑在低级新档（多数玩法锁着）→ **作废，用 GM 满级档重跑**；
- 证据中存在 `rev_match: false`、`anomalies` 非空、`strictBytesEqual: false` 或未接写接口靠默认成功兜底放行 → **全部打回立项为 BUG**；
- 标“视觉通过”却从未真实读图核验 → **标为 `待视觉审`**。

## 第二步：静态契约与常见协议雷区审计

1. **回包字段契约扫描**：遍历已实现协议，对照客户端读包代码核对必读字段；使用 `lua-pbc` / Proto2 时，专项检查 `optional` 0 值与空数组是否在入库口和回包层双向补 `0`/`{}`；纯 Lua PB 核查负数 `int32` 是否输出 10 字节 64 位 varint。
2. **随机池与年月表核查**：非固定奖励池（`WEIGHT`/`LIMIT`/`ONCE`/`LEVEL`）连抽 20 次验证不会扣券发 0 奖；所有按年月查表（如 `sign_YYYYMM`）验证跨年后有循环/默认兜底不报 `nil`。
3. **写接口防假成功检查**：确认任何未实现的消耗/发奖/写档协议不会静默返回成功。

## 第三步：T1–T5 设备端五件套深测（在唯一锁定测试设备串行跑）

### T1 全按钮深度递归爬虫（或命令桥全路由遍历）
- 在 **GM 满级全解锁档**从主城递归遍历所有按钮、子场景与子页签（去重防环，点前 `ensure_fg` 验前台）；
- 经 `qa_oracle.py` 汇总全部报错、异常协议与缺资源日志，产出 `work/analysis/button-coverage.md`（未覆盖项逐条写明原因）。

### T2 文字自动体检
- 抓取遍历到的所有可见文本节点，自动匹配 `undefined`、`NaN`、`null`、`[object`、未替换模板符（`$1`/`%s`/`{0}`）、异常空占位；目标 **0 命中**。

### T3 全部带战斗玩法真打对账（胜 + 负各至少一次）
- 对每个战斗模式在真设备上跑通：`进入 → 开打 → 原版引擎真实算胜负 → 结算 → 奖励/体力/次数账本对账 → 冷启核对`；
- 必须同时验证**胜与负**（确认战败不残留孤立 `pending` 锁死存档），并核查 AI 对手战力曲线是否随玩家成长。

### T4 高等级 30 分钟长稳压测 + 原子写档/强杀自愈
- 在 **GM 满级全解锁档**跑至少 3 轮 × 30 分钟随机点击（不同起点场景）；Android `monkey` 必带防系统误触参数：
  `-p <pkg> --pct-trackball 0 --pct-nav 0 --pct-majornav 0 --pct-anyevent 0`；
- **事务强杀与自愈测试**：在战斗结算、领奖、代金券充值瞬间 `am force-stop`，冷启验证存档未坏、不丢扣款、不重发（`tx_key` 幂等）；额外抽验模拟主存档截断/残留 `.tmp` 时能否通过 `主 → .bak → .tmp` 正常自愈。

### T5 10 日虚拟时钟连续模拟 + 跨年 + 负例守门
- 独立测试档向前连续推进 10 个自然日（并抽测跨月/跨年日期），核对每日重置、签到、月卡/战令、限时活动到期收尾与每日资源产出；
- 全量负例（未达成提前领、跳档领、10 连重复点、0 资源消耗、时钟回拨 `-1d`）必须 100% 拒签且账本零变化。

## 第四步：封版「清数据 + 空热更 + 真断网双冷启」与发行门禁

**最容易在上线前翻车的环节，必须单独作为封版硬门槛执行：**

1. **清数据 + 空热更重装**：彻底卸载/清空测试包数据并确认外部热更目录为空，**仅安装最终正式 APK**（零 PC、零 `adb reverse`、零热推文件），验证不会因跳过首次解压导致缺音效/空 map 或依赖旧热更缓存才跑通。
2. **真断网双冷启（核换新 PID）**：用目标 UID `iptables`（测毕撤回）或带外看门狗真断网（或已剥离 `INTERNET` 权限），连续执行 **2 次完整冷启动（确认前后 PID 不同）**：首次建角进主城打 1 关存盘 → 强杀 → 二次冷启校验进度/背包/货币字节或字段完全一致，`logcat` 0 致命异常、0 `LUA ERROR` / `NullReferenceException`。
3. **自然零 GM 新号抽查**：正式包全新空档自然推前几章，核验强引导弹窗无死锁与数值衔接顺畅。
4. **真实视觉审图**：对启动页、主城、活动栏、战斗结算、代金券充值、养成、抽卡、排行榜等关键截图真实读图确认无叠字/错位/绿白块/白屏/调试白字/GM 按钮泄露。
5. **发行门禁逐项勾选**：
   - [ ] `debuggable=false`、开发热加载/文件命令桥/全量 `print` 日志在正式包内**已物理关闭并断言**；
   - [ ] `aapt dump permissions` 确认纯包内版无 `INTERNET`（或内嵌回环版零外联 SDK 流量）；
   - [ ] 所有音频/扩展包条目存储属性正确（`ZIP_STORED`），无超 ZIP32 上限损坏；
   - [ ] 正式包与 GM 包配对验签通过，旧包已按 `disk_budget.py` 裁剪，设备 `/data/local/tmp` 已清零；
   - [ ] 用户原正式档 SHA-256 与应用 UID 属主（`chown`/`chmod 0600`）完好无损。
