# 🎮 Offline Game Revival

### Навык (skill) для ИИ-агента, который возвращает к жизни мобильные игры с закрытыми серверами — полностью офлайн, на настоящем телефоне.

**Серверы умирают — игра не должна.**

Каждый год закрываются сотни мобильных игр. APK по-прежнему лежит на телефонах игроков, но без сервера он не может ни войти в аккаунт, ни загрузить сохранение — вообще ничего. Годы историй, персонажей и воспоминаний оказываются недосягаемыми.

**Offline Game Revival** — это проверенный в боях сборник приёмов, оформленный как [Agent Skill](https://docs.claude.com/en/docs/claude-code/skills). Укажите своему агенту для программирования (Claude Code и другим агентам, читающим `SKILL.md`) APK мёртвой игры — и он знает, как превратить её в **автономное памятное издание**: ставите APK и проходите всю игру без сети, без root, без ПК и без внедрения кода во время выполнения.

## ✨ Что внутри

| | |
|---|---|
| 🔍 **Разведка** | Распаковка APK, поиск настоящего слоя логики (Lua / JS / транспилированный C#), выявление шифрования и проверок целостности ресурсов. |
| 🧩 **Патчинг с проверяемыми якорями** | Единая точка входа для сборки. Каждая замена кода проверяет свой якорь: если исходный пакет изменился, сборка *громко упадёт*, а не молча выпустит сломанный патч. |
| 🖥️ **Локальный фальшивый сервер** | Перехватывает слой HTTP/JSON и отвечает на сотни эндпоинтов из локального сохранения. Включает методику: выяснить, кто вызывает каждый эндпоинт и что он читает, а затем сгенерировать безопасные значения по умолчанию. |
| 📦 **Репак и переподпись** | Пересчёт контрольных сумм кеша движка, пересборка таблиц ресурсов, zipalign, подпись. Включает алгоритм контрольной суммы кеша, восстановленный реверс-инжинирингом, и патчи загрузчика для LayaAir native. |
| ✅ **Приёмка на устройстве** | «Экран открывается» ≠ «работает». Состояние должно реально меняться и переживать холодный перезапуск. Тестирование по обучению: проходите шаги внутриигрового гайда настоящими нажатиями. |
| 🎞️ **Спасение данных из скриншотов и записей экрана** *(новое)* | Серверные числа (цены в магазине, шансы гачи, награды, характеристики карт) умирают вместе с сервером. `scripts/harvest.py` превращает **десятки ГБ скриншотов и записей экрана от игроков** в несколько сотен КБ структурированного по категориям текста: ключевые кадры → удаление почти-дубликатов → локальный OCR → группировка по экранам — **полностью офлайн, ноль токенов**, а затем `scripts/llm_structure.py` пакетно прогоняет результат через DeepSeek / OpenAI / Qwen / Kimi / локальный Ollama и сливает всё в единые JSON + CSV. |
| ⏩ **Тесты с перемоткой времени** *(новое)* | `scripts/timewarp` запускает ваш фальшивый сервер в песочнице с виртуальными часами: перематывайте дни, перезапускайте приложение и **проверяйте каждую награду** — если в ответе написано «+50 кристаллов», а сохранение не изменилось, тест падает. Симулируйте 30 дней игры за секунду и смотрите, на какой день становится достижим каждый барьер. Ноль зависимостей. |
| 🤝 **Любой агент, любая модель** *(новое)* | Работает с Claude Code, Codex, Cursor, Copilot, OpenCode, Gemini CLI… через `SKILL.md` + `AGENTS.md`. В комплекте роли субагентов (scout / worker / verifier): дорогая модель принимает решения, дешёвые делают всю черновую работу. Совсем нет агента? Вставьте `prompts/chat-playbook.md` в DeepSeek / ChatGPT и выполняйте команды, которые он выдаст. |
| 📚 **Журнал неудач** | 80 КБ реальных граблей: симптом → первопричина → решение. Падения из-за гонок при запуске, UI, который тихо уехал за пределы экрана, объекты XHR из пула, «отравленные» фальшивыми ответами, сохранения, которые так и не попали на диск… |

## 🏆 Проверено на реальных играх

Сборник приёмов выведен из воскрешения двух коммерческих мобильных игр, серверы которых закрылись:

- **Случай A — Unity + Lua**: полноценная одиночная памятная сборка, проверенная на физическом телефоне с Android 14.
- **Случай B — LayaAir native + JavaScript**: 315 серверных эндпоинтов, заново реализованных локально, более 700 регрессионных проверок, и все основные системы (главы сюжета, бои, гача, питомцы, свидания, башня, события) вручную пройдены на устройстве.

Оба разбора (анонимизированы) лежат в [`references/`](../skills/offline-game-revival/references).

git clone https://github.com/Cynthia-wlan9509/offline-game-revival

Затем просто попросите: *«Серверы этой игры закрыли — сделай её играбельной офлайн»* или *«Вытащи цены в магазине и шансы гачи из этих 15 ГБ записей экрана.»*

## 🎞️ Спасение данных из записей экрана (отдельно от агента)

Сборщик данных работает и без всякого агента:

```bash
pip install -r skills/offline-game-revival/scripts/requirements.txt
python skills/offline-game-revival/scripts/harvest.py ./player_recordings ./out --limit 50   # trial run
python skills/offline-game-revival/scripts/harvest.py ./player_recordings ./out              # full run, resumable
export DEEPSEEK_API_KEY=sk-...                                                               # или OPENAI_API_KEY, DASHSCOPE_API_KEY… (PowerShell: $env:DEEPSEEK_API_KEY="sk-...")
python skills/offline-game-revival/scripts/llm_structure.py ./out --limit 2                  # структурировать 2 фрагмента и проверить качество
python skills/offline-game-revival/scripts/llm_structure.py ./out                            # всё целиком → out/structured/merged.json
```

- **Только значимые ключевые кадры**: кадр сохраняется, лишь когда экран *изменился и устоялся* — анимации переходов и размытие в движении пропускаются; длинные прокручиваемые списки всё равно дискретизируются.
- **Дедупликация между источниками**: один и тот же экран из скриншота и из записи объединяется (строка состояния игнорируется).
- **Локальный OCR** (RapidOCR / ONNX, только CPU, CJK + латиница) с рамками и порядком чтения.
- **Результат**: фрагменты `for_llm/*.txt`, а также готовый промпт и JSON-схема в [`media-harvest.md`](../skills/offline-game-revival/references/media-harvest.md); `llm_structure.py` сливает все ответы и помечает противоречащие друг другу числа.

## 🧭 Философия

1. **Патчить при сборке, а не во время выполнения.** Скрипт Frida, который «работает», приходится внедрять вечно. Изменения, зашитые в пакет, просто ставятся и работают.
2. **Единая точка входа + проверка якорей.** Молча пропущенные замены дают сломанные сборки.
3. **Артефакты — не исходники.** Чините скрипт патча, а не правьте результат вручную.
4. **«Открывается» — не значит «работает».** Проверяйте изменения состояния и их сохранение после перезапуска, записывайте, что проверено, а что лишь реализовано.

## ⚖️ Ответственное использование и отказ от ответственности

Этот репозиторий нужен для того, чтобы **изучать, как устроены игры**, и сохранять игры, официальная поддержка которых прекращена. В нём есть только методы и собственные инструменты автора.

- **Здесь нет загрузок.** В репозитории нет игровых ресурсов, игрового кода, ключей расшифровки или подписи и установочных пакетов, и загрузки здесь не предлагаются. Пожалуйста, не просите их здесь.
- **Не давайте сборкам расходиться.** Используйте то, что сделаете, только лично и некоммерчески, с законно полученной копией. Пожалуйста, не публикуйте и не перепродавайте изменённые установочные пакеты, игровые ресурсы или ключи и не запускайте частные серверы ради заработка.
- **Только для игр, чья официальная поддержка прекращена.** Пожалуйста, не используйте это для работающих игр, читерства, обхода античита или во вред другим игрокам и правообладателю.
- **Соблюдайте законы своей страны; за своё использование отвечаете вы сами.** В России Гражданский кодекс охраняет программы для ЭВМ, а декомпиляция допускается лишь в узких случаях; распространение изменённых версий, частные серверы и продажа читов могут повлечь гражданскую и даже уголовную ответственность. В других странах правила другие. Ничто здесь не является юридической консультацией и не утверждает, что какое-либо конкретное использование законно. Если сомневаетесь, проконсультируйтесь с юристом до начала работы.
- **Никакой связи с игровыми компаниями.** Названия игр и товарные знаки принадлежат их владельцам. Проект не связан ни с одной игровой компанией и не одобрен ими.
